# A6 全屋效果图方案：现代简约 × 北欧

本套方案承接已确认的四房布局：西侧普通阳台并入客厅；南墙放电视；南次卧从东侧公卫前过道入户；西南挑空庭院保留客厅侧玻璃，西侧保持联通；餐厅西侧为开放书房，北侧实墙靠高书柜，柜前放独立书桌；厨房入口居中加宽。

## 使用这套成果

- `blender/A6_modern_nordic.blend`：单一全屋模型，家具、墙体与相机处于同一坐标系。
- `blender/build_apartment.py`：可重新生成模型与参考渲染的脚本，尺寸以米为单位。
- `blender/model_manifest.json`：模型假设、家具外包络、相机坐标、焦距及几何校核数据。
- `参考渲染/`：Blender 直接输出，作为布局及透视关系依据。
- `最终效果图/`：以对应 Blender 图为依据生成的饰面、灯光与软装效果。
- `生图提示词.json`：每个视角所使用的提示词及约束。

## 配色与材质

主色采用暖白与浅米灰，木色采用低饱和浅橡木；鼠尾草绿、灰蓝和少量陶土色用于局部织物。深灰金属只出现在窗框、灯具、把手及少量家具细节。不同房间沿用同一组材料，避免每间换一种装修语言。

| 部位 | 设计选材 | 表现方式 |
|---|---|---|
| 客餐厅、书房、卧室地面 | 浅橡木多层实木地板，哑光，直铺 | 连续木纹，减少复杂拼花；与阳台交界的构造依现场深化 |
| 普通墙面 | 暖白哑光涂料 | 轻微真实肌理，避免大面积亮面或复杂线条 |
| 天花 | 同色暖白 | 平整为主，局部灯槽或设备收口，不做繁复吊顶 |
| 定制柜 | 暖白哑光柜门＋浅橡木饰面 | 平板门，窄缝；局部开放格与封闭柜组合 |
| 厨房台面 | 暖白细颗粒石英石 | 同色或相近浅色挡水、墙面，减少纹理干扰 |
| 厨房、生活阳台、卫浴 | 浅灰米色哑光瓷砖 | 模型按约600毫米网格示意；真实防滑等级、铺贴及排水另按使用部位选定 |
| 庭院 | 灰米色室外适用地砖 | 与室内色调接近，保留必要防水、排水与高差 |
| 沙发、软包床头 | 米灰耐用织物 | 细密织纹；床头降低体量，保留通行 |
| 窗帘 | 暖白纱帘＋燕麦色遮光帘 | 向两侧收拢，保留落地窗有效采光 |
| 地毯 | 米白／浅灰低绒织物 | 客厅一张为主，不伸入厨房、卫浴或庭院通道 |

## 各空间的软装重点

- 客厅：燕麦色沙发、浅色低绒地毯，两三个鼠尾草绿／陶土色抱枕；电视墙保持安静，以比例和材质为主。
- 餐厅：浅木餐桌与米灰坐垫餐椅，一盏体量较小的暖白吊灯；装饰集中在桌面小花器。
- 开放书房：书籍与少量器物分散陈列，留出空格；显示器和桌灯控制体量，桌面朝客厅，窗在侧面。
- 西侧休闲区：单椅、小边几，纱帘过滤侧光；柜体与植物均不占庭院入口。
- 主卧：暖白床品、浅木和鼠尾草绿床尾织物，少量床头灯；衣物集中进入衣帽区。
- 东北套房：沿用浅木与暖白，以灰蓝织物作轻微区别。
- 南次卧：暖白＋少量陶土色，保持正式卧室功能，优先床边通道与衣柜。
- 北次卧：暖白＋鼠尾草绿，窗边学习桌与衣柜整合成清爽的小卧室。
- 庭院：浅木或耐候材质户外座椅、可拆洗浅色坐垫、少量盆栽；不增加夹层、楼梯或玻璃顶封闭构造。
- 卫浴：浅灰米色瓷砖、浅木洗手柜、细框镜面及少量深灰五金，减少落地杂物。

## 建模精度与已确认条件

模型使用原宣传图的15.2米东西向、17.8米西侧南北向尺寸链，以及逐间推算的标称跨度。四间卧室的0.6米窗边带已按用户确认纳入可用落地范围；书房北侧实墙、南次卧东侧门位和两个阳台的联通关系已纳入模型。

主卫生间按约2.1×2.7米的标称范围建模，没有把未确认的卫生间南侧窗边带计入可用地面。卧室窗边带的确认不自动套用于卫生间。

但原图不是测绘或施工图。墙体统一采用约120毫米的示意厚度；普通3米层高暂按150毫米楼板表示，天花底面约2.85米；庭院6米层高对应上方板底约5.85米。这些是透明列出的建模假设，不能当成已知净高。门窗高度、楼板梁位、设备点位和局部墙垛仍需现场资料。

所有室内透视相机均位于模型可用区域内，采用约18～28毫米焦距；小卫浴和生活阳台使用较宽视角，未通过隐藏房间墙体扩大空间。室外仅表达柔和天空，不代表现场景观。模型为统一的尺寸、视角校核基础；生成图用于材质和氛围表达，施工与定制仍以复尺和深化图为准。
