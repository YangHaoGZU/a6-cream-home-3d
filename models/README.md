## 多视角预览

1. 使用 `/Applications/Blender.app` 打开 `A6-modern-minimalist-v3.blend`。
2. 时间轴切到第 **1–16 帧**，会自动切换各房间相机。按数字小键盘 **0** 进入相机视图；无小键盘可用「视图 → 摄像机 → 活动摄像机」。
3. 按 **Z → 渲染** 预览真实材质光影；按 **F12** 输出当前相机渲染（默认1600×1000，Cycles96采样）。Mac 可使用菜单「渲染 → 渲染图像」。
4. 中键拖动旋转视图，Shift+中键平移，滚轮缩放。`Shift + \`` 开启步行导航，WASD移动，鼠标转向，左键确认、Esc退出。
5. 右上大纲中的「04 现代简约 · 官网尺寸重建家具」可以按家具父对象查看结构；选中父对象，在「对象属性 → 自定义属性」查看实物来源与官方尺寸。
6. 顶视平面可隐藏「01 吊顶 · 可隐藏查看平面」集合。渲染前恢复显示。
