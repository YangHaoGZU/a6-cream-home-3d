# A6 法式自然风 · 空间总览与全景

基于 A6 房开户型的轻量三维空间导航和 24 点位 AI 全景，适配电脑与手机。

- 两个入口：空间总览、全景漫游。默认展示总览，保留全景点位直达链接。
- 总览从米制户型数据在本地构建，6,574 个三角面、10 个绘制批次；相比旧模型的 823,104 个三角面减少约 99.2%。不下载 GLB、模型纹理、城市贴图或解码器，不使用后处理和实时阴影；静止时不持续绘制。
- 用暖白墙面、亚麻色沙发、浅木色家具、藤编色椅背和人字拼瓷砖缝表现新风格。家具与墙体采用简化剖切模型，普通层高 3m、挑空阳台 6m，剖切显示高度不代表真实层高。
- 模型中显示 24 个编号点位，可点击进入对应全景，另有可键盘操作的点位列表。拖动旋转、双指缩放和平移、滚轮、长按及取消手势不会触发跳转，拖动从标记位置开始也能正常操作模型。
- 24 张法式自然风全景用内置 AI 编辑，每个点位直接以最初的 Blender v3 全景为唯一图像参考，未使用前一轮 AI 图像叠加生成，也未重新进行 Blender 渲染。逐张对照主要墙角、门窗开口、家具轮廓与占地，修正餐桌形状、主卧门洞及衣帽间端墙、走廊封闭端墙。局部软包轮廓、卫浴挡水沿、栏杆和跨视角地面纹理仍有偏差；保留的模型坐标不等于 AI 像素经过几何校准，图片不是测量或施工依据。
- 总览沙发外廓 228×95×83cm；餐桌 200×78×74cm；主卧与北套房床架 196×209cm，南北次卧床架 166×209cm，床头高度 100cm。床架尺寸不等于床垫尺寸。
- 全景默认水平视角不超过 90°、垂直不超过 75°，减少宽屏边缘的广角拉伸；仍可手动缩放。这只改变显示视角，不修正图像本身的几何。
- 图片经 TinyPNG 实际压缩；先加载 768×384 预览，再加载完整全景。选图抽屉中的预览按需加载，房间切换会释放上一张图片的 GPU 资源。

## 本地运行与发布

```sh
npm ci
npm run dev
npx tsc --noEmit
node checks/overview.mjs
npm run check:mobile
npm run check:panorama
npm run build
```

使用 Node.js 22.13 及以上版本。GitHub Pages 发布 `main` 分支的 `/docs`，构建后提交 `docs/` 并推送。所有地址均为相对地址，支持仓库子路径。

`checks/overview.mjs` 检查模型复杂度和边界、24 个点位、两种界面模式、14 类手势。`check:mobile` 验证屏幕比例和总览相机边界；这些自动检查不能替代 iOS / Android 真机测试。

## 文件与尺寸

- `lib/plan.ts`：米制户型、标注尺寸链、门窗位置及实际层高。横向尺寸链 15.2m、西侧纵向 17.8m、东侧 16.7m，未标注细尺寸按图估算。
- `lib/furniture-layout.ts`：家具位置、尺寸和朝向，南北次卧床头靠西，主卧和北套房床头靠东。
- `lib/overview-model.ts`：轻量法式自然风模型。
- `lib/overview.ts`、`lib/overview-gesture.ts`：轨道控制、点位投影、点击判定。
- `lib/panorama-data.ts`：24 个点位、关联关系及图片缓存版本。
- `public/panoramas/manifest.json`、`render-info.json`：实际图片分辨率、文件字节数、AI 来源及 TinyPNG 压缩记录。

替换 TinyPNG 全景与预览后运行 `node scripts/prepare-panoramas.mjs --keep-previews`，验证尺寸并更新清单。该参数保留已经压缩的预览，不再重新编码。

原 Blender 文件和现代简约模型资料保持归档状态，当前页面不会加载它们。历史细节见 [现代简约版本记录](README-modern-history.md)。
